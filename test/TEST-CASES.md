## 测试结果文件命名规范

- **命名格式**：`TEST-RESULTS-YYYY-MM-DD-HHmm.md`
- **精度**：精确到分钟（HHmm），确保同一日内多次测试不会互相覆盖
- **示例**：
  - `TEST-RESULTS-2026-06-29-1415.md` — 2026年6月29日 14:15 执行
  - `TEST-RESULTS-2026-06-30-1020.md` — 2026年6月30日 10:20 执行
- **规则**：每次测试创建新文件，不覆盖已有记录

### TC-207：浏览器后退按钮
- **前置条件**：已登录，在专家聊天页面
- **操作步骤**：
  1. 按浏览器后退按钮
  2. 再按前进按钮
- **预期结果**：后退回到门诊首页，前进回到专家模式
- **实际结果**：⚠️ PARTIAL — 后退后页面内容正确切换回门诊模式，但 URL 仍保留 `?context_module=mock_interview`，SPA 路由与浏览器 history 不同步
- **严重程度**：Low
- **Bug 描述**：SPA 内部状态与 URL 参数不同步，后退按钮触发路由变化但 URL 未更新

### TC-208：Deep Link — ?agent=xxx 参数
- **前置条件**：已登录
- **操作步骤**：
  1. 访问 `?agent=career_mentor`
  2. 访问 `?agent=nonexistent_agent`
- **预期结果**：
  - 有效参数：直接激活对应专家
  - 无效参数：显示欢迎页，不崩溃
- **实际结果**：❌ FAIL — `?agent=` 参数未生效，页面显示门诊模式。实际使用的参数是 `?context_module=`
- **严重程度**：Medium
- **Bug 描述**：Deep link 参数名与 PR Review 中指定的 `agent` 不一致，代码实际使用 `context_module`
- **修复建议**：统一参数名，或同时支持 `agent` 和 `context_module`
